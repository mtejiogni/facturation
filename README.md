# 📃 Facturation Service Informatique

> Aplication Web de gestion des factures - HTML, CSS, JS, PHP, MYSQL

---

## ⚙️ Outils techniques

HTML5 -- Pour la structure des pages
CSS3 -- Pour la mise en forme et le resonsive web design
JS -- Interactions et calculs dynamiques
PHP 8+ -- Logique Serveur et accès BDD

---

## 📦 Installation des bibliotheques

```bash
# Font Awesome
npm install @fortawesome/fontawesome-free
```

---

## 🎯 Lancement

```bash
# 1. Cloner le projet
git clone https://github.com/mtejiogni/facturation.git

# 2. Installer les dependances npm
npm install

# 3. Importer la base de donnees
mysql -u root -p < conception/facturationdb.sql

# 4. Copier le projet dans le dossier serveur 
# WAMP --> C:/wamp64/www/facturation

# 5. Demarrer le serveur WAMP puis ouvrir le lien :
# http://localhost/facturation
```
